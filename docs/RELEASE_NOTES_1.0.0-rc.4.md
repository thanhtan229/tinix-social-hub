# Tinix Social Studio 1.0.0-rc.4

- Export toàn bộ account và Chrome profile vào một file `.tinix-profiles.zip`.
- Import toàn bộ profile từ file ZIP trong một lần và tự tạo account cùng tên/nền tảng.
- Dùng chung định dạng ZIP với Tinix FB Down.
- Giữ khả năng Import gói thư mục `.tinix-profile` v1 cũ.
- Kiểm tra ZIP chống path traversal, symlink, đường dẫn trùng và dung lượng giải nén bất thường.
